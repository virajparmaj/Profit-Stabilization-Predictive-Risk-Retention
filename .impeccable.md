## Design Context

### Users
This project serves a mixed audience of research and business stakeholders exploring MEPS 2023 affordability, delay, access, and low-risk subsidy questions. Users need to move fluidly between presentation-grade summary views and interactive data exploration while staying anchored in exact survey variables and weighted population estimates.

### Brand Personality
Evidence-first, polished, exploratory. The interface should feel credible enough for academic discussion, clear enough for stakeholder review, and dynamic enough to invite hands-on exploration without reading like a generic BI dashboard.

### Aesthetic Direction
Use an editorial analytics direction with presentation-level visual impact. Favor a bright, paper-tinted canvas with warm neutrals, deep ink text, and a few saturated accents for semantic emphasis. Avoid default enterprise dashboard tropes, flat card grids, neon dark themes, and generic “AI dashboard” styling.

### Design Principles
1. Every chart must teach: pair each visualization with an exact reading guide, explicit labels, and a computed inference that updates with filters.
2. Let the evidence lead: preserve variable names, survey caveats, weighting choices, and proxy disclaimers in the UI wherever interpretation could drift.
3. Balance rigor with momentum: keep the overview scannable, then let deeper sections support richer exploration without overwhelming first-time viewers.
4. Make the interface feel designed, not templated: use strong typography, layered backgrounds, and intentional composition rather than repeated commodity panels.
5. Keep interaction honest: use local static data, recompute from the filtered cohort, and clearly mark what is directly answerable versus proxy-only or not answerable from MEPS.
